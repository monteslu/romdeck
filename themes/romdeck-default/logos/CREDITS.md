# Shelf system wordmarks

Generated by `scripts/make-shelf-logos.mjs`. Regenerate with:

```bash
node scripts/make-shelf-logos.mjs
```

## What these are

Each file is a system's name set as **outlined SVG paths** — not live `<text>`,
and not an imitation of any console's logo.

They are outlined rather than set in a web font for two reasons. Live `<text>`
renders with whatever typeface the viewer happens to have installed, so the
same wordmark looked different on every platform. And bundling a font to fix
that would ship ~668 KB for the 34 capitals and digits these actually use.
Outlining pins the letterforms *and* ships no font: the whole set is ~85 KB.

## Why not real console logos

Console logos are trademarked artwork. The community themes romdeck can
*download* (Art Book Next, Modern, Slate) carry 20–220 MB of that artwork under
CC-BY-NC-SA, and none of it is romdeck's to bundle. A system's name set in a
typeface is not a logo, so these are ours to ship — see `THEME_CATALOG` in
`src/main/themes.js` for the wider fetch-don't-bundle reasoning.
